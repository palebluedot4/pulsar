# RFC 9207: OAuth 2.0 Authorization Server Issuer Identification

Clauses of [RFC 9207](https://www.rfc-editor.org/rfc/rfc9207) that pulsar,
as an authorization server, must or should meet.

- REQ-ISS-1 (§2.3): "The server MUST indicate its support for the iss
  parameter by setting the metadata parameter
  authorization_response_iss_parameter_supported, defined in Section 3, to
  true."

- REQ-ISS-2 (§2): "In authorization responses to the client, including
  error responses, an authorization server supporting this specification
  MUST indicate its identity by including the iss parameter in the
  response."

  The error page, shown when the Client or redirect URI is invalid, is not
  an authorization response to the Client, so it has no `iss`.
