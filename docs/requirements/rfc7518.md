# RFC 7518: JSON Web Algorithms (JWA)

Clauses of [RFC 7518](https://www.rfc-editor.org/rfc/rfc7518) that pulsar,
as an OP that signs with RS256 and publishes RSA public keys as JWKs, must
or should meet.

- REQ-JWA-1 (§3.3): "A key of size 2048 bits or larger MUST be used with
  these algorithms."

  This holds for the keys Clients register for `private_key_jwt` too: the
  registry refuses a smaller RSA key, for RS256 and for PS256, of which
  §3.5 says the same.

- REQ-JWA-2 (§3.3): "The RSASSA-PKCS1-v1_5 SHA-256 digital signature is
  generated as follows: generate a digital signature of the JWS Signing
  Input using RSASSA-PKCS1-v1_5-SIGN and the SHA-256 hash function with the
  desired private key. This is the JWS Signature value."
- REQ-JWA-3 (§6.3): "JWKs can represent RSA [RFC3447] keys. In this case,
  the "kty" member value is "RSA"." §6.3.1: "The following members MUST be
  present for RSA public keys."
- REQ-JWA-4 (§2, Base64urlUInt): "The octet sequence MUST utilize the
  minimum number of octets needed to represent the value."
- REQ-JWA-5 (§6.3.1.2): "For instance, when representing the value 65537,
  the octet sequence to be base64url-encoded MUST consist of the three
  octets [1, 0, 1]; the resulting representation for this value is
  "AQAB"."
