# RFC 7517: JSON Web Key (JWK)

Clauses of [RFC 7517](https://www.rfc-editor.org/rfc/rfc7517) that pulsar,
as an OP publishing its signing keys in a JWK Set, must or should meet.

- REQ-JWK-1 (§4.1): "The "kty" (key type) parameter identifies the
  cryptographic algorithm family used with the key, such as "RSA" or "EC".
  [...] This member MUST be present in a JWK."
- REQ-JWK-2 (§4.5): "When "kid" values are used within a JWK Set,
  different keys within the JWK Set SHOULD use distinct "kid" values."
- REQ-JWK-3 (§5): "The JSON object MUST have a "keys" member, with its
  value being an array of JWKs."
- REQ-JWK-4 (§9.2): "Private and symmetric keys MUST be protected from
  disclosure to unintended parties."
